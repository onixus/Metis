# Локальные JSON-профили коннекторов

Этот каталог по умолчанию монтируется только для чтения в `/etc/metis` у API и worker. Он не содержит активной конфигурации и не включает обращения к реальным системам. Примеры и параметры: [интеграции](../../../docs/integrations.md), [1С и финансы](../../../docs/integrations-1c.md).

Рабочие профили храните вне репозитория и задавайте их каталог через `METIS_CONNECTOR_CONFIG_DIR`. Секреты передавайте из хранилища секретов; `METIS_CONNECTOR_ENV_FILE` может ссылаться на отдельный локальный файл для имён переменных из профилей 1С. Не записывайте значения секретов в этот каталог.
