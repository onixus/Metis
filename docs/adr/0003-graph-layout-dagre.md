# ADR-0003. Иерархическая раскладка графа портфеля на dagre

Статус: принято · Дата: 2026-09-17

## Контекст

Граф портфеля (PG-09) рисуется на React Flow. Круговая раскладка без зависимостей плохо читается: рёбра пересекаются, направление «потребитель → поставщик» не видно. Нужна иерархическая раскладка, где зависимые продукты стоят над хабом-поставщиком, а раскрытые узлы с фичами не накладываются.

## Рассмотренные варианты

| Вариант | Лицензия | Оценка |
| --- | --- | --- |
| `@dagrejs/dagre` | MIT | Слоистая раскладка Sugiyama, учитывает размеры узлов, работает синхронно в браузере, ~60 КБ |
| `elkjs` | EPL-2.0 | Лицензия вне списка NF-L02 — запрещён |
| `d3-hierarchy` | ISC | Только деревья; граф портфеля — DAG с несколькими корнями |
| Собственная реализация | — | Дороже сопровождения, чем зависимость на 60 КБ |

## Решение

Зависимость `@dagrejs/dagre` (MIT) во фронтенде. Раскладка `rankdir=TB`: рёбра идут от потребителя к поставщику, поэтому хабы оказываются внизу. Размеры узлов передаются в dagre с учётом раскрытых списков фич. Перетаскивание пользователем сохраняется до нажатия «Разложить заново» или изменения структуры графа.

## Последствия

Одна новая npm-зависимость, проверяемая license-checker в CI. Раскладка пересчитывается на клиенте за миллисекунды при расчётном масштабе 50 продуктов.
