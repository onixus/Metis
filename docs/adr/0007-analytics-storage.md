# ADR-0007. Аналитическое хранилище и конструктор дашбордов (DA-05)

Статус: принято · Дата: 2026-09-18

## Контекст

Раздел 7.2 ТЗ называет ClickHouse «с этапа 3» и Apache Superset для DA-05 (конструктор дашбордов
через встроенный BI). DA-05 имеет приоритет S. Расчётный масштаб платформы из раздела 8 —
десятки продуктов, тысячи фич и сигналов, финансовые данные по периодам: объём, который PostgreSQL
обслуживает материализованными представлениями без отдельного колоночного хранилища.
Superset — отдельный сервис со своей моделью пользователей, доступом к данным и обновлениями
безопасности; его встраивание означает второй контур авторизации над теми же финансовыми данными,
где действует NF-S02.

## Рассмотренные варианты

| Вариант | Оценка |
| --- | --- |
| Оставить аналитику в PostgreSQL, DA-05 — сохранённые определения дашбордов поверх API платформы | Один контур доступа, ABAC и уровни финансового доступа работают без дублирования; ограничение — тяжёлые произвольные срезы по большим объёмам |
| ClickHouse + Superset сейчас | Два дополнительных сервиса в поставке и в реестре ПО, второй контур авторизации, рост стоимости стенда; данных для колоночного хранилища пока нет |
| Только ClickHouse, BI позже | Перенос витрин без потребителя, который требует такой скорости |

## Решение

Этап 3 остаётся на PostgreSQL. DA-05 реализуется как конструктор дашбордов платформы: пользователь
сохраняет определение дашборда (набор панелей со ссылкой на срез API, измерения и фильтры), платформа
отдаёт данные теми же сервисами и тем же `authz.Scope`, что и остальной API. Внешний BI не встраивается.

ClickHouse и Superset откладываются до подтверждённого объёма данных или требования заказчика на
произвольные срезы. Условие пересмотра: время ответа дашборда портфеля по производственным данным
превышает NF-P01, либо заказчик требует собственные отчёты вне набора панелей платформы.

## Последствия

Отклонение от таблицы стека ТЗ 7.2 — зафиксировано этим ADR и строкой в `docs/questions.md`.
Витрины остаются материализованными представлениями PostgreSQL; при переходе на ClickHouse
определения дашбордов сохраняются, меняется только источник данных панели.
