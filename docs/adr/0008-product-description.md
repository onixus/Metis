# ADR-0008: описание продукта как часть карточки

Статус: принято. Дата: 2026-09-22.

## Контекст

PG-01 не задаёт поле назначения продукта. Пользователь требует содержательных
карточек репозиториев: роль, границы, источники и зрелость нельзя выражать названием.

## Решение

Добавить необязательное поле `description` (обычный текст, до 12000 символов)
в ProductInput/Product. Домен валидирует размер; отсутствие поля при обновлении
сохраняет описание, явная пустая строка очищает его. PostgreSQL получает новую
миграцию с TEXT NOT NULL DEFAULT ''. Описание подчиняется тем же правам просмотра
и записи, что остальные стратегические атрибуты продукта; секреты и персональные
данные в него не помещаются. UI отображает экранированный текст с переносами.

Связи и возможности используют существующие сущности PG-02/03/04. Источники и
границы достоверности фиксируются в описании и в материалах анализа. Отдельный
коннектор Git и автоматическое назначение финансовых данных не вводятся.

## Последствия

Обратная совместимость HTTP и БД сохраняется. Прежние клиенты не затирают описание.
Разметка HTML/Markdown не исполняется. Новых зависимостей нет.
