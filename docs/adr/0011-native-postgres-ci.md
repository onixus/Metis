# ADR-0011: PostgreSQL CI из пакетов Ubuntu

- Статус: принято
- Дата: 2026-10-10

## Контекст

PR #53 повторно не доходит до Go-тестов: Docker Hub возвращает таймаут
аутентификации или ограничивает анонимные загрузки pgvector/pgvector:pg16.
PostgreSQL 16 и pgvector уже входят в стек; отключение integration недопустимо.

## Решение

Закрепить Go job на ubuntu-24.04 и установить postgresql-16 и
postgresql-16-pgvector через подписанные apt-репозитории runner. Новых библиотек
приложения нет; лицензии PostgreSQL и pgvector — PostgreSQL License,
разрешительный вариант BSD. Сопровождение пакетов выполняют поставщики
репозиториев Ubuntu/PostgreSQL; minor-обновления не закрепляются.

Создавать собственный кластер под RUNNER_TEMP, не изменяя существующие кластеры
runner. Сервер слушает 127.0.0.1:55432; TCP требует SCRAM, Unix socket находится
в закрытом каталоге. Используется только синтетический пароль тестового стенда.
Проверять major 16 и реальное создание extension vector. Runtime-тесты сохраняют
отдельную БД и ограниченную роль metis_app. Остановка выполняется всегда,
при ошибке сохраняется лог сервера. Все прежние quality/security gates остаются.

## Последствия

Исключается Docker Hub из запуска Go job, но доступность пакетных реестров
остаётся необходимой. Версия pgvector зависит от репозитория пакетов; текущая
схема использует FTS и не имеет vector-колонок. Будущие требования к версии
расширения должны закрепляться отдельно и проверяться на этом CI.
Альтернатива — зеркало Docker image — добавила бы обслуживание и доверие
к ещё одному registry без необходимости контейнеризации тестовой БД.
