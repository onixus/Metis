# ADR-0012: сохраняемый конструктор финансовых показателей

Статус: принято. Дата: 2026-10-10. Issue: #26.

## Контекст

Modeling имеет собственную семантику версий полей/формул и данных периода; книги economics не заменяют его (ADR-0009). MemStore теряет все определения и историю при restart.

## Решение

Добавить схему modeling с INSERT-only ревизиями типизированных JSONB-документов. SQL фиксирует вид, устойчивый ключ, номер ревизии, product_id и время UTC. Доменные структуры остаются источником формата документов; деньги/decimal сериализуются без float. sqlc генерирует запросы. Глобальные определения используют нулевой product_id и права полного портфеля согласно ADR-0010; продуктовые строки проверяют Scope. Ни один запрос не обращается к чужой схеме.

Поля и показатели сохраняются только с неизменным ID и полным неизменным префиксом предыдущих версий плюс одной новой версией; устаревшие/переписанные версии отклоняются. Batches, facts и версии правил добавляются однократно. Шаблоны, команды, сценарии и доли команд имеют добавляемые ревизии; текущие списки выбирают последнюю. Закрытие периода идемпотентно и хранит автора. Роль metis_app получает SELECT/INSERT, без UPDATE/DELETE.

Записи сериализуются транзакционной application lock; импорт и ручные значения оборачиваются транзакцией через доменный порт. API использует существующую общую транзакцию, scheduler — ту же границу приложения. Состояние, аудит и outbox откатываются вместе. При отсутствии PostgreSQL остаётся MemStore.

## Последствия

Добавление схемы обратно совместимо; старый бинарник её игнорирует. Данные прежнего MemStore автоматически восстановить нельзя. JSONB облегчает сохранение существующей модели; рост истории и переход к более узким блокировкам требуют отдельного измерения. Объединение экономических контуров остаётся #34. Новых библиотек/лицензий нет.

NF-S16: пока источник численности отсутствует, team reports закрыты для нефинансовых ролей независимо от размера команды (вопрос 46). Право на сырые финансовые строки остаётся прежним FinanceFull; политика выдачи этого уровня задаётся IdP.
