# ADR-0014: APEX Design System

## Статус
Принято, 2026-10-22. Основание: issue #56.

## Решение
Пока @onixus/apex-tokens не опубликован, значения из issue хранятся только в web/src/tokens.css. Существующие семантические имена становятся aliases. Hub — категория viz-5, не статус. Состояние темы хранится в apex.theme; default dark, system следует ОС. Инициализация отдельным модулем до загрузки React. Печать всегда light.

Новые зависимости: lucide-react (ISC, поддержка Lucide), @fontsource-variable/inter и @fontsource-variable/jetbrains-mono (MIT для пакетов, SIL OFL-1.1 для шрифтов, поддержка Fontsource). Fontsource поставляет font assets локально, без CDN. OFL-1.1 разрешается исключительно для файлов шрифтов как исключение NF-L02: свободное использование/встраивание с сохранением лицензии; имена шрифтов не меняются. Лицензионный gate сохраняется и явно включает OFL-1.1.

## Последствия
Нет сетевого запроса за шрифтами. Токены и контраст проверяются в CI. Замена на общий пакет — отдельный dependency upgrade. API, роли и данные не меняются.
