# ADR-0015: исправленные версии для полного CI #56

Статус: принято, 2026-10-22.

## Контекст
Полный CI #57 заблокирован текущими Go 1.27.2 и Excelize 2.11.0: Go vulnerability database сообщает GO-2026-6809 и GO-2026-6684/6685/6688/6689. Security-gate сохраняется без новых исключений.

## Решение
Go повышается до 1.27.3. Excelize (существующая зависимость BSD-3-Clause, ADR-0005) закрепляется на 2.11.1-0.20260930021559-01a9ff32fb3c: это наиболее поздняя из исправленных версий, указанных в finding metadata. В реестре нет стабильного 2.11.1. Изменение ограничено существующими зависимостями, проверяется govulncheck, полным race/integration gate, XLSX fixtures и лицензиями.

## Последствия
Использование prerelease требует отдельного обновления после выхода стабильного релиза. Никакая новая уязвимость не добавляется в allowlist. Существующее исключение GO-2026-6452 оценивается отдельно; wrapper и ограничения импорта сохраняются.
