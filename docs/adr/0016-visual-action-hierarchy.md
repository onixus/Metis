# ADR-0016: иерархия действий и вкладки APEX

Статус: принято, 2026-10-23. Основание: DS56 / визуальная приёмка #57.

## Контекст
Заполненный трек сертификации показывает восемь primary-кнопок одновременно; карточка продукта и решение — по две. Несколько карточек/форм могут быть открыты одновременно. Это нарушает требование одной primary-кнопки на экран. Общие вкладки также не поддерживают клавиши стрелок и могут обрезаться вместе с фокусом на узких экранах.

## Решение
На составном экране primary закреплена за основным действием страницы (создать фичу, начать трек, новое обязательство/решение, добавить roadmap item). Действия строк, панелей и вложенных форм используют обычную кнопку с теми же focus/disabled состояниями. В самостоятельном редакторе/входе primary — отправка формы. Активная вкладка — tab с aria-selected, а не primary-команда.

Общий Tabs поддерживает roving tabindex, ArrowLeft/Right, Home/End, пропуск disabled и уникальные имена групп. На мобильном вкладки переносятся строками; 2px focus ring рисуется внутри кнопки, не обрезаясь контейнером. Новых зависимостей нет. Доменные права и API не меняются.
