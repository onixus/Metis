# ADR-0017: границы gate дизайн-системы

## Статус
Принято, 2026-10-23; review PR #57, DS56/NF-L02/NF-S04.

## Решение
OFL-1.1 из ADR-0014 разрешается только для двух явно закреплённых версий Fontsource: Inter и JetBrains Mono 5.3.0. Общий production allowlist остаётся прежним. Эти два пакета отдельно проходят проверку OFL-1.1 и наличия поставляемых notices; смена версии требует пересмотра исключения. Используется существующий license-checker, новых зависимостей нет.

Визуальный стенд эксклюзивно создаёт новый каталог 0700. Существующий путь, включая symlink, отвергается до сборки, chmod и записи файлов. Повторный запуск требует нового пути; артефакты предыдущего запуска сохраняются. Cleanup токенов выполняется и при ошибке запуска.

Каждая заявленная HTTP-проба должна утверждать ожидаемый статус, а обязательные формы — присутствовать в сценарии. Отсутствие ожидаемого контрола является падением, а не пропуском.

## Последствия
Регрессии gate запускаются в CI. Production API, ABAC, тема и схема данных не меняются; прежняя визуальная галерея сохраняет исходный provenance, новый прогон фиксируется отдельно.
