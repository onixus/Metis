# ADR-0022 — Одна явная валюта бюджетного сценария

Дата: 2026-10-25. Статус: принято. Требования: DA-02, EC-13, архитектурный инвариант 6.

## Контекст

Конструктор экономики формирует P&L в `Config.Currency`. Сценарий складывал `BudgetDelta.Amount` с бюджетом и сравнивал результат со стоимостью треков без проверки валюты. Численно корректный результат мог означать сумму разных валют.

## Решение

До сохранения и повторно при расчёте отклонять изменение бюджета с другой валютой или ненулевую сумму без валюты. Стоимость треков проверять перед агрегацией по тем же правилам. Пустая нулевая сумма означает отсутствие изменения/затрат и допускается для совместимости с существующими сценариями. Если поле бюджета определено, его действующая на период версия должна быть денежной и в валюте модели. Конвертации нет; клиент получает ошибку валидации вместо ложного дефицита.

## Последствия

Существующий ошибочный сценарий остаётся в истории, но не вычисляется до исправления. Фактические данные не меняются. Причинность сдвига обязательств и общий дефицит по трекам остаются прежними и требуют отдельной работы.
