# ADR0032 — ручные значения общего конструктора в канонической книге

Статус: принято, продолжение итерации28.

После объединения независимые model batches запрещены. Ручное поле общего конструктора не должно создавать второй источник факта и не должно оставаться без пути записи. SetManualValue сохраняет прежние проверки источника/типа/валюты/периода/Scope и делегирует связанному canonical writer.

Порт получает опубликованную эффективную версию поля, book owner, исходный/common key и product/team/item slice. Старый namespaced key обратно отображается в исходный manual key книги; новый key допускается в пределах лимита64. Только app writer может выдать закрытый контекстный grant на проекцию одного опубликованного manual определения в схему книги. Обычный API настройки книг не может выдать такой grant и по-прежнему не меняет общие определения.

Перед заменой значения одно ручное поле нормализуется из точной аллоцированной проекции в строки с нулевой direct_cost суммой по product/team/item. Его manual Values удаляются с прежних строк; исходные внешние суммы и все другие поля остаются прежними. Это сохраняет распределение других продуктов и не прибавляет новое значение поверх старого. Старые финансовые версии сохраняют исходные значения/источники. ModelItem хранит необязательную статью модельного среза, не подменяя лист источника. Новый ввод заменяет одну нормализованную группу.

Запись использует обычный CAS и общий PostgreSQL-контекст с аудитом. Закрытый период не изменяется. Ответ ссылается на новую canonical snapshot ID/version, legacy model batch не создаётся. Поля import/calculated не принимают ручной ввод; неизвестная команда, несовместимые определения, выход за лимит строк/полей и переполнение отклоняются целиком.
