# План итерации 01 — каркас

Требования: раздел 7.1, 7.2, 7.4 п.1; NF-O01, NF-O04, NF-S11, NF-L02, NF-M01.

## Состав

1. Go-модуль `github.com/onixus/metis`, структура каталогов раздела 7.2.
2. `cmd/api`: HTTP-сервер (chi), `/healthz`, `/readyz`, OpenTelemetry (traces stdout/OTLP по конфигурации), метрики Prometheus, структурные логи JSON (slog).
3. `cmd/worker`: каркас воркера outbox с `SKIP LOCKED`.
4. CI (GitHub Actions): gofmt, go vet, golangci-lint (errcheck, staticcheck, gosec, depguard), тесты `-race`, govulncheck, go-licenses, gitleaks, npm license check, SBOM CycloneDX.
5. Compose-стенд: PostgreSQL 16 + pgvector, Keycloak, мок Jira (WireMock-совместимый образ на фикстурах).
6. Документация: AGENTS.md, ADR-0001 (стек), ADR-0002 (outbox на PostgreSQL), docs/questions.md.

## Критерий готовности

`make ci` зелёный локально; `/healthz` отвечает 200; trace и метрики выдаются.
