# План итерации 05 — сигналы и порт CRM

Требования: SG-01, SG-02, SG-03, SG-05 (ТЗ 3.2); порт CRM (ТЗ 4.1, 4.2: идемпотентность по внешнему ключу, CRM только на чтение); правило ценности контракта (ТЗ 2.4); сценарий приёмки 7.7 п.3 и п.6. SG-04 — этап 2, не входит.

## Состав

1. `internal/ports/crm.go` — порт CRM: `Account`, `Deal` (сумма и ARR — `kernel.Money`, регуляторное требование сделки, запрошенные фичи), интерфейс `CRM` только на чтение.
2. `internal/adapters/crmfile` — адаптер CSV-выгрузок (`accounts.csv`, `deals.csv`): маппинг по заголовкам, лимит размера файла, значения — только строки (формулы `=`, `+`, `-`, `@` не интерпретируются). Синтетические фикстуры `fixtures/crm/`. Контрактный тест на фикстурах.
3. `internal/signals` — домен:
   - `Signal`: `ProductID` обязателен (SG-02); источник `crm|service_desk|manual|import` (SG-01); опциональные `AccountID`, `DealID`, `Version`, `Segment`; `Weight` (сумма сделки или ARR аккаунта) и `AccountARR`; `BlocksDeal`; статусы triage `new|in_review|linked|rejected|merged` и `DueDate` (SG-03); привязка `FeatureID` / `ContractID` / `HypothesisID` (гипотезы — этап 2, поле зарезервировано) (SG-05); `ExternalKey` для идемпотентного импорта.
   - `Store` + `MemStore`.
   - `Service`: `Ingest`, `ImportFromCRM`, `Triage`, `LinkToFeature`, `LinkToContract`, `Signal`, `TriageQueue`, `ARRByFeature`, `BlockedDealsByFeature`. При привязке пересчитывается `OwnValue` фичи (`portfoliograph.SetFeatureOwnValue`) или `SignalValue` контракта (`SetContractSignalValue`) как сумма весов всех привязанных сигналов.
   - События `signals.signal.ingested|triaged|linked` через `kernel.Publisher`.
   - Каждый метод принимает `authz.Scope`; чтение — `ActionReadPrivate`, запись — `ActionWriteSignals`.
4. Тесты: `TestSG01_*`, `TestSG02_*`, `TestSG03_*`, `TestSG05_*`, тест отказа ABAC (PM VM не видит сигналы EDR), сценарий приёмки: сигнал со сделкой 12 млн ₽ привязан к контракту → `Contract.SignalValue` = 12 млн.

## Критерий готовности

`gofmt`, `go vet`, `golangci-lint` без замечаний; `go test -race` для `internal/signals/...`, `internal/adapters/crmfile/...` зелёный; каждый ID покрыт тестом с ID в имени; ABAC-отказ протестирован; `go.mod` не изменён.
