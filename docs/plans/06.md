# План итерации 06 — prioritization (PR-01…PR-03)

Требования: PR-01, PR-02, PR-03 (ТЗ 3.4); правила 2.4 (производный спрос PG-07); инварианты 1–3, 6, 9, 10.

## Состав

1. `internal/prioritization/formula.go` — безопасный вычислитель арифметических выражений:
   числа, `+ - * /`, скобки, унарный минус, идентификаторы, функции `min`/`max`.
   Лимиты длины (1024 символа) и глубины (32). Деление на ноль и неизвестная переменная/функция — `kernel.ErrValidation`, без паники.
   Расчёт в `shopspring/decimal`.
2. `internal/prioritization/model.go` — `ScoringModel` (ID, ProductID или портфельная при NilID, Name, Type rice|wsjf|custom, Formula, Inputs),
   встроенные формулы RICE (`reach*impact*confidence/effort`) и WSJF (`(user_business_value+time_criticality+risk_reduction)/job_size`),
   `FeatureInputs` (значения переменных для фичи), `ScoreResult` (Score, компоненты, пояснение).
3. Порты: `MoneyMetrics` (PR-02, реализует signals) и `DerivedDemand` (PR-03, реализует `*portfoliograph.Service`).
   Системные переменные `arr`, `blocked_deals`, `own_value`, `derived_value`, `total_value` — деньги в основных единицах (`Amount/100`, decimal).
4. `store.go` — `Store` + `MemStore`. `service.go` — `Service`: CreateModel/UpdateModel/Models, SetFeatureInputs, Score, Ranking.
   События `prioritization.model.saved`, `prioritization.inputs.set`.
5. ABAC: модель продукта — `ActionWritePriority(productID)`; портфельная — `ActionWritePriority(NilID)` (CPO/admin);
   чтение — `ActionReadStrategic`; входы — `ActionWritePriority`. Нулевой Scope запрещает всё.
6. Тесты: `TestPR01_*`, `TestPR02_*`, `TestPR03_DerivedDemandRaisesHubFeatureScore`, отказ ABAC, property-тест вычислителя (rapid).

## Не входит

PR-04, PR-05 (этап 2); HTTP-обработчики и миграции — в итерации httpapi/db.

## Критерий готовности

`go vet`, `golangci-lint`, `go test -race ./internal/prioritization/...` зелёные.
