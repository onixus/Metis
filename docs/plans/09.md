# План итерации 09 — слой хранения PostgreSQL (outbox, миграции, sqlc, PG-хранилища)

Требования: NF-R02, NF-R06 (ТЗ 5.2), правила коннекторов 4.2 (outbox, повторы, DLQ), AD-04, NF-S05,
ADR-0002 (outbox на PostgreSQL), инварианты 2, 5, 7, 8, 9, 10, 11; сценарий приёмки 7.7 п.8.

## Состав

1. Зависимости: `github.com/jackc/pgx/v5` (MIT), `github.com/pressly/goose/v3` (MIT) — уже в таблице ADR-0001.
2. `internal/kernel/pgdb` — `DB{pool}`, `Open(ctx, url)`, `Transact(ctx, fn)` кладёт `pgx.Tx` в контекст,
   `Querier(ctx, db) DBTX` возвращает транзакцию из контекста или пул. Все PG-хранилища берут querier из контекста.
3. `internal/kernel/outbox` — `Store` (интерфейс над `kernel.outbox`/`kernel.outbox_dlq`), `MemStore` (unit-тесты),
   `PGStore` (sqlc, `FOR UPDATE SKIP LOCKED`), `Publisher` (kernel.Publisher, пишет в outbox в текущей транзакции),
   `Worker`: пачки, маршрутизация по `Event.Type` на несколько `kernel.Handler`, экспоненциальная задержка,
   после `MaxAttempts` (по умолчанию 10) — DLQ с текстом ошибки; `DLQCount`, `DLQList`, `Requeue`.
   Гарантия at-least-once; обработчики идемпотентны по `Event.ID`.
4. Миграции goose: `db/kernel/migrations/00001_outbox.sql`, `db/audit/migrations/00001_audit.sql`
   (триггер, запрещающий UPDATE/DELETE; REVOKE от `metis_app`, если роль есть), `db/portfoliograph/migrations/00001_graph.sql`.
   `db/embed.go` (`//go:embed */migrations/*.sql`), `internal/kernel/migrate` — программный запуск goose по всем каталогам.
5. sqlc: `sqlc.yaml` в корне, запросы в `db/<module>/queries`, код в `internal/<module>/internal/db` (не правится вручную).
6. Хранилища: `audit/pgstore.New(db)`, `portfoliograph/pgstore.New(db)` (подпакеты вне `internal/`, чтобы depguard
   не пропускал pgx в доменные файлы). Реализации в `internal/<module>/internal/{store,pgstore}`.
7. `cmd/worker/main.go`: конфигурация из `METIS_DATABASE_URL`, `METIS_MIGRATE`, `METIS_OTEL_EXPORTER` (пока slog JSON),
   graceful shutdown по SIGTERM/SIGINT.
8. Тесты: без БД — `TestNFR06_WorkerRetriesThenDLQ` (MemStore); с БД (`-tags integration`, `METIS_TEST_DATABASE_URL`,
   вопрос №05) — `TestNFR06_OutboxDeliversAndRetriesToDLQ`, `TestNFS05_AuditTableRejectsUpdateDelete`,
   `TestAD04_PGAuditChainVerify`, `TestPG_PGStoreRoundTrip`.

## Не входит

OpenTelemetry-экспортёр, HTTP API, seed, `cmd/api`, materialized views аналитики.

## Критерий готовности

`gofmt`, `go vet ./...`, `go vet -tags integration ./...`, `golangci-lint`, `go test -race` по своим пакетам зелёные.
