# План итерации 10 — сборка приложения, API, seed, приёмка

Требования: 7.4 п.5–10, DA-03 (дашборды в web), 7.7 (сценарий приёмки), NF-O01, NF-O04, NF-M04.

## Состав

1. `api/openapi.yaml` — единый источник; серверные интерфейсы (`internal/httpapi/gen`), Go-клиент e2e (`tests/e2e/client`), типы фронтенда (`web/src/api/schema.d.ts`).
2. `internal/httpapi` — аутентификация Bearer (OIDC или HMAC стенда), маппинг ошибок в problem+json, 409 с путём цикла.
3. `internal/app` — сборка модулей: хранилища (память / PostgreSQL), outbox, воркер, адаптеры Jira и CRM, наблюдаемость.
4. `internal/seed` — два референсных портфеля.
5. `tests/e2e` — сценарий 7.7 целиком в процессе на моке Jira из фикстур compose.
6. `deploy/helm`, `deploy/compose` — поставка.
7. `web` — граф, бэклог, roadmap, дашборды продукта, хаба, delivery.

## Критерий готовности

`go test ./...` включая `TestAcceptanceStage1` зелёный; `golangci-lint` без замечаний; `npm run build` проходит.
