# Итерация 14 — проверка локального стенда

Запрос: «стенд проверь». 2026-09-22.

До изменения кода проверены контейнеры, health/readiness, 19 продуктов в PostgreSQL,
карточки/Delivery через API, финансовый отчёт, очередь ошибок и вход в браузере.
Найдены два дефекта: опубликованная ссылка `/products` не имеет маршрута SPA;
Compose запускает сверку Delivery раз в час при пороге устаревания 15 минут.

План (PG-09, DA-03, NF-R05):
1. Добавить защищённое перенаправление `/products` на существующий список `/`.
2. Установить интервал Delivery в Compose 5 минут; явный override сохранить.
3. Проверить web lint/typecheck/tests/build и развёрнутый Compose config.
4. Пересобрать и обновить существующий стенд без удаления данных.
5. Повторить вход по `/products`, проверить список/карточку, состояние Delivery,
   здоровье сервисов и сохранность 19 продуктов; записать результаты.

API, схема БД и доменные правила не меняются. Новых зависимостей нет.
Для маршрута и настройки применяется проверка на работающем стенде;
новые искусственные unit-тесты маршрута/литерала конфигурации не добавляются.

## Результат

Оба исправления развёрнуты в `metis-pilot-iteration12` на порту 18083.
Браузерный сценарий: вход с `/products` → список из 19 продуктов → карточка
Shapoclyack → актуальный Delivery → контрольная книга EDR за 2026-09.
P&L: выручка 9 млн RUB, прямые затраты 3,9 млн, нагрузка хаба 0,6 млн,
прибыль 4,5 млн; версия 1 сохранилась после обновления.

Web lint/typecheck, четыре существующих теста и production build прошли.
Docker build/up завершены успешно; оба процесса имеют интервал `5m`.
Health/readiness — HTTP 200, ошибок уровня ERROR/HTTP 5xx после обновления нет,
рестартов процессов нет, pending outbox и DLQ — 0.
Проверка API до обновления охватила карточки, features и Delivery всех 19 продуктов,
финансовый отчёт, links/hubs/decisions/admin и отказ без токена (401).

Новые Git-продукты содержат карточки; фичи, финансовые данные и привязки к Jira
для них ещё не импортированы. Jira/Confluence остаются локальными моками.
Проверка не включает реальную внешнюю интеграцию, нагрузку и восстановление из backup.
