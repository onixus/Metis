## Исправленные замечания

1. Лишние primary-команды в карточке продукта, сигналах, решениях, гейтах и релизах: одна основная команда составной страницы, вложенные действия — обычные кнопки (ADR-0016).
2. Вкладки теряли клавиатурную навигацию и обрезали фокус: общий Tabs с roving tabindex, disabled-aware arrows/Home/End; перенос строк на мобильном экране.
3. Заполненные шаблоны треков расширяли мобильный документ: таблица теперь прокручивается внутри карточки, колонки не сжимаются до одной буквы.
4. Release notes и контролы вне `.field` имели нативную серую палитру: общие токенизированные стили, доступное имя release notes и контрастная граница checkbox/radio.
5. Статусы фич/жизненного цикла не имели значка и subtle фона: используются Badge; inline ошибки финансовых форм получили семантическое оформление.
6. Inline color-scheme побеждал print CSS: печать принудительно light, таблицы переносятся, бренд не обрезается.

## Воспроизведение

Требуются Go из go.mod, Node 24+, Python 3 (стандартная библиотека) и операторская установка Playwright/Chromium. Новые runtime/dev зависимости в package.json не добавлены. В двух терминалах из корня checkout:

```sh
npm --prefix web ci
npm --prefix web run build
# Новый ещё не существующий путь; существующие каталоги отвергаются (ADR-0017).
python3 web/scripts/visual-stand-ds56.py --temp-dir /tmp/metis-ds56-repro --port 18059
```

После `stand ready` во втором терминале:

```sh
export METIS_ACCEPTANCE_TEMP=/tmp/metis-ds56-repro
export METIS_ACCEPTANCE_URL=http://127.0.0.1:18059
# При нестандартной установке задайте METIS_PLAYWRIGHT_MODULE и METIS_CHROMIUM_PATH.
node web/scripts/acceptance-ds56.cjs
node web/scripts/acceptance-session-ds56.cjs
```

Результат — `final/matrix.json`, `session-matrix.json`, снимки и CSV/PDF во временном каталоге. Стенд создаёт одноразовый HMAC-ключ и токены в файле 0600 внутри каталога 0700; при остановке удаляет файл токенов. Перед пересборкой frontend остановить стенд и затем запустить заново: production handler читает index.html при старте. Скриншоты не включают действующие токены.

## Граница доказательств

Это визуальная приёмка Chromium настоящего локального API с memory/HMAC и синтетическими данными. Она не выдаётся за проверку внешнего OIDC/Keycloak, настоящего Atlassian/CRM, других браузеров, production/deployment или устройства. PostgreSQL/отдельный worker проверяются полным CI отдельно. Поведение OIDC-провайдера не изменялось. Ручная проверка человеком по NF-L01 остаётся на стороне reviewer; статус ready означает готовность PR к этому review, без merge.
