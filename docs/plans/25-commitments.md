# Итерация 25 — Roadmap и обработка рисков обязательств

Дата: 2026-10-25. Запрос владельца: завершить Roadmap и обязательства с агентами.

До кода: CT-01…04, RM-01…06 и исторический остаток #32 сверены с ТЗ и текущим кодом. План24 посвящён параллельной экономике и здесь не изменяется.

1. ADR-0020 и вопрос фиксируют минимальную политику: владелец риска по умолчанию владелец обязательства; назначение, ручная эскалация с явным адресатом и заметки сохраняются append-only. Новых SLA и внешних каналов уведомлений не предполагается.
2. OpenAPI до реализации: история действий и владелец риска в алерте, ручная запись действия; повторная генерация Go/TypeScript. Дополнительное поле Forecast.sync раскрывает существующий публичный контракт доставки.
3. Реализовать scoped Store/Service/API/UI и события аудита; новая совместимая миграция, отказные CT03 и PG-регрессии.
4. Исправить CT03 дедупликацию MemStore и CT04 календарный горизонт, добавить граничные тесты.
5. Проверить race, web typecheck/lint/build и PG при доступном стенде; честно зафиксировать автоматические уведомления/SLA как отдельную приёмку.

Изменения пишет агент Codex; человеческое ревью ожидается. Существующие изменения экономики сохраняются.

## Выполнено

- CT-03: API `/commitment-alerts/{alertId}/actions`, текущий владелец риска и append-only история назначения, эскалации и заметок; форма обработки и история доступны в реестре. Запись событий outbox и hash-chain аудит HTTP-действий/подтверждения подключены к существующей транзакции runtime. Подтверждение не означает исполнение.
- Новая миграция `commitments/00003_risk_actions.sql` сохраняет историю; триггер и права приложения запрещают UPDATE/DELETE. Scoped репозитории проверяют доступ и принадлежность алерта продукту.
- CT-01: runtime проверяет принадлежность привязанных фич/релизов через публичные порты модулей.
- CT-03: MemStore, как PostgreSQL, запрещает повтор пары «обязательство + событие».
- CT-04: календарный горизонт ограничивается концом целевого месяца; тесты 31 января в обычный/високосный год и 31 марта.
- Контракт Forecast расширен существующим DeliverySync; samples ограничены 0…100000, 0 использует 10000.

## Проверки

- `go test -race ./internal/commitments/... ./internal/httpapi/...` PASS, включая CT03 HTTP round-trip/чужой продукт/валидацию/целостность аудита, CT03 owner/actions/refusals/immutability, CT01 link ownership и CT04 month-end.
- `go test -tags integration ./internal/commitments/pgstore -run '^$'` PASS — только компиляция интеграционных тестов. Реальный PG-прогон не подтверждён: тестовая БД недоступна. Новый PG-тест проверяет сохранение через новый экземпляр репозитория, отказ чужого продукта/нулевого Scope и запрет изменения истории.
- Web lint, typecheck и production build PASS; OpenAPI Go/TypeScript/sqlc перегенерированы.

## Границы

Автоматический SLA, канал доставки адресату, автоматический переход обязательства в breached и конкретный справочник ответственных не придуманы; вопрос51 и ADR0020 сохраняют границы. Эскалация — запись внутри Metis, интерфейс явно предлагает связаться с адресатом по согласованному каналу. Повторный POST обработки — новое историческое действие; idempotency key не заявлен. Продакшен не развёртывался, полная готовность релиза не заявляется. Человеческое ревью ожидается.
