## Агент Roadmap: релизы (RM-04/05)

- Создание релиза с `ready_for_certification` отклоняется до записи; переход остаётся только через проверяемую команду готовности. Регрессия проверяет обе ветки, отсутствие записей/событий и отсутствие обходного вызова readiness.
- Редактор релиза показывает доступные действия: выпуск, завершение поддержки; сохраняет готовность при обычном редактировании и блокирует смену ветки выпущенного релиза. Отдельная команда EOL теперь позволяет очистить дату.
- ADR-0021 фиксирует существующие правила и пределы процесса. Обратные переходы статуса запрещены, чтобы возврат в planned не обходил неизменяемость выпущенной ветки. Дополнительное согласование выпуска и замораживание состава/notes/дат не вводятся. Описание OpenAPI уточнено; общую генерацию выполняет агент обязательств.
- Проверено: `CGO_ENABLED=1 go test -race ./internal/roadmap/...` — PASS; web lint/typecheck — PASS. PostgreSQL-интеграция и браузерное изменение статусов этим агентом не запускались.

Браузерная проверка выявила, что пустая строка EOL не проходила strict JSON date decoder. Контракт команды EOL уточнён до required nullable date, UI отправляет `null`, обработчик использует общий `dateOf`. Добавлена HTTP-регрессия `TestRM05_ReleaseEOLHTTPNullableClear`: установка даты, отказ пустой строки без изменения данных, снятие через null. Targeted HTTP race test и web typecheck PASS, Go/sqlc/web генерация выполнена.

## Дополнительные регрессии после браузерного прогона

Браузер поймал некорректную отправку пустой строки при очистке EOL. OpenAPI теперь явно разрешает `null`, hook передаёт `null`, сервер переводит его в пустую дату. `TestRM05_ReleaseEOLHTTPNullableClear` проверяет дату → отказ пустой строки без изменения → успешную очистку через null. Контракт и все клиенты перегенерированы. Финальные целевые RM/CT/DL/runtime race-тесты и весь web-gate повторены — PASS.

`TestDL04_HTTPForecastExposesHistoryAndStaleness` проверяет реальный HTTP-ответ со статистикой и устаревшей синхронизацией, а также отказ отрицательного/избыточного samples. `TestDL04_ExhaustedSimulationDoesNotReturnFabricatedCompletion` проверяет отсутствие ложной даты при исчерпании бюджета. Оба PASS. ADR прогноза перенумерован в 0024, чтобы не конфликтовать с параллельной экономикой.
