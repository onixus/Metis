# Итерация 28 — интерфейс прямых источников формул

До кода, EC-09/10/13: дополнить существующий конструктор вставкой типизированных source-функций и русским описанием единиц/недоступности. Объяснение показывает снимок, время, срез, точную captured-сумму, сценарный override и происхождение без перевода decimal в Number. Сценарии выбирают либо поле, либо прямой источник, source допускает необязательную точную команду; API получает взаимоисключающие source/field_key. Результат сценария раскрывает именно возвращённые базовые и сценарные объяснения, без нового чтения источников.

Проверки: регрессии сериализации source/team override и точного int64, обычные поля сохраняют формат; web lint/typecheck/test/build. Браузерный сценарий будет выполнен на настоящем PostgreSQL-стенде основной сессии, с синтетическими источниками и без моков API. Новый metadata-компонент выделяется отдельно для переиспользования без circular imports. EconomicsPage/UnificationPanel не изменять. Новых зависимостей нет; автор Codex, человеческое ревью pending.

## Реализация и локальная проверка

Конструктор вставляет source-функции и объясняет недоступность/замороженные источники. Сценарий выбирает source вместо field_key, допускает точную team_id, сериализует int64 строкой и показывает возвращённые базовые/сценарные объяснения. Компонент сценария сбрасывается при смене продукта/месяца; форма ручного ввода использует эффективную версию поля исторического периода.
