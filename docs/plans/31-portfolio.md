# Итерация 31 — портфель и иерархия UI

План до кода: [31.md](31.md). Реализовано агентом Codex; человеческое ревью pending.

- PG-01/06: PM может редактировать свой продукт. Создание и удаление продукта остаются у CPO/admin; ручное назначение хаба PM не меняет. Тип продукта независим от роли хаба; убрана принудительная замена типа на `platform`. Временные draft IDs генерируются без module-level mutable counter.
- PG-02: приватный блок «Возможности → фичи → требования» использует новые серверные GET и существующие POST. Возможности и требования читаются после reload. Создание/изменение фичи позволяет выбрать существующую возможность; старые фичи без привязки остаются видны. Нет нового API удаления/изменения возможностей и требований: добавление сохраняет историю.
- PG-08: результат сдвига раскрывает затронутые фичи, продукты, плановые/вычисленные даты и обязательства. Изменение ввода убирает прежнее сообщение о результате.
- PG-09/10: портфель показывает доступные продукты, хабы, связи, владельцев, жизненный цикл и РБПО независимо от финансового доступа. Ссылки на граф предустанавливают продукт. Финансовая часть монтируется только при наличии finance level. Приватная иерархия не монтируется для strategic-only доступа.
- Подключён ContractsPanel основного агента в карточку продукта. Старая read-only таблица сохранена как экспорт для HubPage.
