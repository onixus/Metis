## Дополнение до исправления PG-08 после review

Подтверждён дефект: сохранённый ImpliedDate использовался как вход нового расчёта, а перенос источника назад вообще не пересчитывал зависимые фичи. Пересчитать effective date всего DAG от поставщиков к потребителям только из актуальных PlannedDate, переопределив плановую дату источника. Для источника сохранить ограничения его собственных поставщиков; для downstream пересчитать/снять устаревшие предупреждения. Регрессии: supplier переносится раньше, source с более поздним upstream supplier переносится раньше, persisted reload. Прежний тест «раньше не затрагивает» заменить проверкой актуального пересчёта по PG-08 §2.4.

## Результат исправлений review PR60

Все три P2 исправлены. Store.ReplaceContract возвращает только вычисленные внутри Store feature projections; контракт, собственные рёбра и derived dates фиксируются атомарно. Память меняется после успеха Store. PG триггер на финальном UPDATE доказывает rollback контракта/рёбер/проекций. Удаление/замена зависимости обновляет downstream и ready_date, а параллельный поставщик сохраняет своё ограничение; успешные значения переживают reload.

Shared ownership учитывает actual feature product_id. Service.CreateLink и Mem/PG Store.SaveLink отвергают чужие/обратные/nonintegration ассоциации и подмену product_id при чужих feature IDs. Legacy варианты сохраняются без изменения чужих feature projections в persistence, cache и reload. Независимое read-only security investigation выполнено до патча; единственный bypass/regression review обнаружил альтернативную подмену владельца фичи, она подтверждена и закрыта дополнительными Mem/PG регрессиями. Решение ADR0035; новых зависимостей/миграций нет.

Win/loss вынесен из P&L и зависит от ActionReadMarketing/портфельного scope, а не finance. Проверены CPO/admin/marketing/service и global-private PM, отказы остальным комбинациям; при finance:none P&L не запрашивается.

После последнего изменения Go-кода: полный `CGO_ENABLED=1 go test -race -count=1 -tags integration ./...` с двумя изолированными PostgreSQL16.14 UTF8/en_US.UTF-8 базами и runtime metis_app — PASS; lint0/vet/CGO0build, 32 frontend tests/lint/typecheck/build, go-licenses/gitleaks и generation40files без изменений — PASS.
