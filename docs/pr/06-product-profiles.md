# feat: содержательные карточки Git-продуктов и зависимости

Созданные ранее карточки содержали только название и тип. Итерация добавляет
редактируемое описание назначения/границ/источников и блок связей с контрактами.
Описание — экранированный текст до 12000 символов; пропуск поля старым клиентом
сохраняет значение, пустая строка очищает. Миграция добавляет колонку с default.
API, sqlc и TypeScript перегенерированы.

В существующем стенде заполнены 9 карточек, 18 возможностей, 50 фич и 50 требований
с источниками. Восемь контрактов создают связи продуктов и конкретных фич;
на графе виден их статус. APEX, Shapoclyack и Metis определены платформами,
остальные — самостоятельными продуктами. Данные и классификация воспроизводимо
описаны в [манифесте](../portfolio/current-git-products.json).

Контракты остаются черновиками до сквозной приёмки; HTTP-клиент, mock и реальное
исполнение различаются. Сроки, владельцы, бюджеты и сертификация не выдуманы.
Исходные репозитории не модифицировались. Повторная загрузка не создала дубликатов.

Проверки и результат — [план 15](../plans/15.md). Тесты покрывают сохранение,
очистку, длину, совместимость старого клиента, отказ доступа и round-trip PG.
Web и Docker сборки прошли; проверка UI выполнена на обновлённом стенде.
API/БД обратно совместимы, зависимостей не добавлено; удалённый CI не запускался.

Код, классификация и заполнение выполнены Codex. Человеческое ревью не выполнено
(NF-L01). README/roadmap источников не заменяют приёмку внешних установок.
