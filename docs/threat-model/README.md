# Модель угроз

Заполняется по мере реализации. Для этапа 5 (LLM-модуль) модель угроз пишется до кода (ТЗ раздел 7).

## Этап 1: границы доверия

- Пользователи проходят через IdP (OIDC). Токен проверяется по JWKS; локальных паролей нет.
- Содержимое из Jira и CRM — недоверенный ввод (NF-S17): экранируется при отображении.
- Роль приложения в БД не имеет UPDATE/DELETE на таблицы аудита (инвариант 8).
- Финансовые данные — отдельный уровень доступа (NF-S02); на этапе 1 финансовых данных нет.
