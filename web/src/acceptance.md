# Приёмка рабочего цикла PM — итерация 12

Синтетические данные; локальный стенд с отключёнными внешними адаптерами. Проверка не требует CRM или Jira. Токены не сохранять в этом файле, скриншотах и отчётах.

## Автоматические проверки frontend

Из `web/`:

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

Node 24+. Четыре регрессии проверяют поздний ответ приватного запроса при смене сессии, callback незавершённой мутации прежнего пользователя, точность копеек и отказ при округлении/переполнении/выражении вместо денежной суммы.

## Браузер: чистый продукт → спрос → приоритет → roadmap

1. Открыть поставляемое приложение. Войти синтетическим CPO. Создать продукт `pilot-ui` / «Пилот UI», тип «ИБ», владелец `pilot-pm`, без начальных фич.
2. Открыть продукт → «Новая фича». Создать «Экспорт событий в SIEM», статус «идея». Она видна в бэклоге и стратегическом срезе. Через «Изменить» сменить имя на «Нормализованный экспорт в SIEM» и статус на «запланирована». После перезагрузки изменения сохранены. У привязанной к трекеру фичи external_key отображается, ввод внешнего статуса недоступен.
3. «Новый сигнал»: текст «Нужен экспорт для пилота», аккаунт `SYN-ACCOUNT`, сделка `SYN-DEAL`, сегмент «B2B», сумма `12000000,01`, ARR `0,29`, флаг «Блокирует сделку». После сохранения запись видна в очереди разбора. Ввести `0,001` либо `90071992547409,92` в отдельной попытке: форма показывает ошибку, запись не создаётся.
4. «Разобрать»: выбрать «в разборе», задать срок и сохранить. Снова открыть разбор и связать сигнал с фичей. Очередь опустела; запись остаётся во «Все сигналы» со статусом «привязан», читаемым названием фичи, аккаунтом и точной суммой. Ценность фичи обновляется. Трассировка открывает связанный сигнал.
5. «Новая модель оценки»: создать RICE «Пилот». «Оценить фичу»: reach `10`, impact `2`, confidence `0,8`, effort `4`. Сохранить: score `4`, фича появляется в ранжировании. Смена параметра сбрасывает старое подтверждение сохранения; повторная оценка обновляет score. effort `0` блокируется. Закрыть и открыть форму: сохранённые параметры восстановлены из компонентов оценки. Аналогично создать WSJF и проверить положительный job_size.
6. Из бэклога «В roadmap»: форма предзаполняет фичу и название. Выбрать «Далее», аудиторию «Можно показывать presale», добавить даты, сохранить. Элемент виден в Now / Next / Later, таймлайне и «Без релиза». Создать второй элемент без дат: он остаётся виден в Now / Next / Later.
7. «Изменить» у первого элемента: поменять название, горизонт, статус и аудиторию. Даты, фича и релиз сохраняются. Отдельной кнопкой «Изменить даты» задать новые даты и причину: история показывает автора, старые/новые даты и причину. Конец раньше начала блокируется.
8. Создать релиз во вкладке «Релизы», назначить его элементу через «Изменить». Элемент появился «По релизам». При выборе сертифицированного релиза форма переключает вид на «исправление»; произвольная фича не проходит гейт сервера.
9. В «Все сигналы» отклонить ранее связанный сигнал. Он остаётся в истории со статусом «отклонён», связь удалена, его денежный вес больше не входит в фичу. Вернуть в разбор, привязать повторно: запись не дублируется.
10. Дополнительный сигнал связать с существующим интеграционным контрактом или гипотезой. В таблице отображается выбранный объект. Подсказки похожих сигналов и объединение доступны в приватном контуре; объединённая запись остаётся видна во «Все сигналы».

## Браузер: смена прав без перезагрузки

1. Под CPO открыть продукт, сырые сигналы, оценку и roadmap. Оставить незавершённый запрос в сети (при необходимости через ограничение скорости).
2. Нажать «Выйти». В той же вкладке войти синтетическим presale. Приватные строки предыдущего CPO не должны появляться даже кратковременно. Нет кнопок создания продукта, фичи, сигналов, моделей, изменения roadmap; в roadmap видны только sales-safe элементы.
3. Выйти и войти PM другого продукта. Прямой URL чужого приватного продукта не открывает бэклог/сигналы; API отвечает отказом. Старые данные не возвращаются после завершения запроса первой сессии.
4. Войти PM `pilot-ui`: создание фичи, ручного сигнала, модели продукта и roadmap доступно; создание портфельной модели этим UI не предлагается. Для роли marketing доступны сигналы/discovery, но отсутствует управление фичами, приоритетами и roadmap.

## Зафиксированные пределы проверки

2026-09-22: lint, TypeScript, production build и четыре node:test выполнены. Через native Safari / CUA в отдельном private окне проверено настоящее приложение с PostgreSQL и отдельным воркером на локальном стенде (внешние адаптеры выключены):

- Вход CPO, создание чистого продукта `pilot-ui-12` и фичи «Экспорт событий в SIEM».
- Переход из фичи в предзаполненный roadmap, создание sales-safe элемента без дат и изменение его названия на «SIEM: экспорт для B2B пилотов». Результат сохранён и позднее прочитан другой ролью.
- Ручной сигнал с аккаунтом `SYN-ACCOUNT`, сделкой `SYN-DEAL`, сегментом B2B, суммой `12000000,01`, ARR `0,29`; смена triage-статуса на «в разборе» и привязка к фиче. Во «Все сигналы» запись осталась со статусом «привязан», названием фичи и точной суммой. Ценность фичи в бэклоге и стратегическом срезе стала `12 000 000,01 RUB`.
- Создание RICE модели продукта, ввод `10`, `2`, `0,8`, `4`, получение score `4` и объяснения с компонентами. Перезагрузка страницы сохранила фичу, её ценность и оценку.
- На финальном production build: выход CPO и вход presale в той же вкладке. Приватные сигналы, бэклог и действия записи отсутствуют. Presale видит стратегический срез и изменённый sales-safe roadmap без кнопок редактирования.
- Выход presale и попытка входа со строкой `invalid-synthetic-token`: после ответа API пользователь остаётся на пустой форме входа; redirect-loop отсутствует.

Матрица выше шире фактически выполненного browser-smoke: изменение статуса фичи, даты/история, ветки релиза, WSJF, другие цели связи, отклонение/возврат сигнала и дополнительные роли остаются шагами расширенной ручной приёмки. Browser smoke не заменяет Go acceptance и PostgreSQL integration/race-проверки.

Сессия завершена выходом, команда закрытия private окна отправлена. Повторное чтение Safari для подтверждения закрытия остановлено автоматическим approval review из-за риска доступа к посторонним вкладкам; обход не выполнялся. Одноразовые synthetic tokens в артефакты не включены.

Удаление фич не добавлено: существующий OpenAPI не предоставляет DELETE. Для завершения жизненного цикла используется «отклонена», сохраняющая связи и историю. Новые API и зависимости не добавлялись.
